## Sobre mí

Desarrollador iOS especializado en el ecosistema Apple. Construyo aplicaciones nativas con Swift y SwiftUI, aplicando arquitectura MVVM y un stack moderno, 100% nativo.

**Mi enfoque técnico:**
- **SwiftData** para persistencia local — sin Core Data, sin ORMs externos
- **async/await** para concurrencia — limpio, legible y no bloqueante
- **Codable** para serialización — tipado seguro, JSONSerialization fuera de mi flujo
- **Cero librerías de terceros** — si Apple lo incluye, lo uso; si no, lo construyo

Formado en **Apple Coding Academy** (Swift Developer Program 2023).
Busco mi primer rol en una empresa donde pueda aportar desde el primer día y crecer dentro de un equipo técnicamente sólido.

## Proyectos

### [iMangas](https://github.com/YerayCastro/iMangas)
**Swift Developer Program 2023 — Proyecto Final @ Apple Coding Academy.**
Gestor de colección de manga que sirvió como base para Mangora. Consume una API REST de manga con `async/await`, almacena datos localmente con SwiftData e integra WebKit para navegación web in-app. Arquitectura MVVM completa con separación clara entre capas de datos, dominio y presentación.

`Swift` · `SwiftUI` · `SwiftData` · `async/await` · `WebKit` · `URLSession` · `Codable` · `MVVM`

---

### [WatchAll](https://github.com/YerayCastro/WatchAll)
App nativa para seguir películas y series de TV. Obtiene datos de una API remota con `async/await` sin bloquear el hilo principal. Interfaz SwiftUI limpia con un diseño minimalista y moderno, siguiendo las Human Interface Guidelines de Apple. Patrón MVVM en toda la app.

`Swift` · `SwiftUI` · `async/await` · `Codable` · `URLSession` · `MVVM`

---

### [RickAndMortyTotal](https://github.com/YerayCastro/RickAndMortyTotal)
Explorador del universo Rick and Morty a través de su API oficial. Personajes, ubicaciones y episodios cargados de forma asíncrona con `async/await` y presentados mediante una arquitectura MVVM estructurada.

`Swift` · `SwiftUI` · `async/await` · `Codable` · `URLSession` · `MVVM`

---

### [Employees](https://github.com/YerayCastro/Employees)
App de gestión de empleados con CRUD completo y persistencia local via Codable — sin frameworks externos. Búsqueda y filtrado nativos. Demuestra una gestión de datos limpia sin dependencias de terceros.

`Swift` · `SwiftUI` · `Codable` · `MVVM`

---

### [MyGarden](https://github.com/YerayCastro/MyGarden)
Tracker de jardín y huerto. Gestiona cultivos, controla plagas y registra el crecimiento de las plantas — todo a través de una interfaz SwiftUI intuitiva respaldada por SwiftData para persistencia local.

`Swift` · `SwiftUI` · `SwiftData` · `MVVM`
